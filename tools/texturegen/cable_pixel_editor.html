画笔（点击角色选中，快捷键 1-0 按图案而定）

操作说明

左键 画 / 右键 擦除（透明）· 拖动 连续绘制 · Shift+点击 直线填充 · 滚轮/+- 无需，16×16 固定。
画的是 模板（角色字符），不是最终颜色——同一模板会按各档面板配色渲染， 固定色角色（W 白点 / N 灰点 / E 描边 / B 亮带 / G 机框 / R 储能红 / O 能量芯）不随档位变化。
储电盒 / 变压器 / 充电座为 IU 红色素材的原图逐像素转写（用户 2026-10-04 定）， 各自带独立调色板，画笔名称/颜色即原图配色，画布所见即原图。
